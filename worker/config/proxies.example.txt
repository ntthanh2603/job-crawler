# Sao chép thành config/worker-proxies.txt trong worker/ (WORKER_PROXIES_FILE; file đó không được
# commit, xem .gitignore). Mỗi dòng một proxy. Dòng trống và phần sau dấu # bị bỏ qua. Các dạng
# được nhận:
#   http://user:pass@1.2.3.4:8080
#   https://1.2.3.4:8443
#   socks5://user:pass@1.2.3.4:1080      (socks5h:// để DNS phân giải ở phía proxy)
#   1.2.3.4:8080                         (mặc định http)
#   1.2.3.4:8080:user:pass               (mặc định http)
# Chromium (render) không dùng được SOCKS có mật khẩu: các proxy đó chỉ dùng cho HTTP thường.
